# MIZAKI · Pakar $IMP$

Laman Bahasa Melayu dengan sembilan halaman. Kandungan, gaya, skrip dan gambar tersedia dalam folder `public/`. Buka `public/index.html` untuk pratonton tempatan.

## Cloudflare Workers

Sambungkan repositori ini kepada Workers Builds. Pilih cawangan `main`, direktori akar repositori dan nama Worker `mizaki`. Biarkan arahan binaan kosong dan gunakan `npx wrangler deploy` sebagai arahan deployment. Wrangler membaca tetapan aset daripada `wrangler.jsonc`.

## Penyuntingan

`public/index.html` mengandungi teks asal. `public/theme.css` mengawal reka letak responsif. Skrip dalam `public/scripts/` menyusun kandungan halaman, navigasi dan galeri. Gambar disimpan dalam `public/media/`.
